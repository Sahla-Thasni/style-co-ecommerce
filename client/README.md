# E-Commerce Project

A full-stack eCommerce application built with React, TypeScript, Django REST Framework, and PostgreSQL.

## Technologies Used

### Frontend
- React
- TypeScript
- Vite
- Material UI
- Redux Toolkit
- React Router
- Axios

### Backend
- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication

## Features

- User registration and login
- Product listing
- Product details
- Product variants
- Product images
- Category and brand filtering
- Shopping cart
- Quantity management
- Checkout
- Product reviews and ratings
- Promo code support
- First-order discount
- Responsive design
