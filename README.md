# STYLE.CO – E-commerce Application

STYLE.CO is a full-stack e-commerce web application for browsing products, managing a shopping cart, and placing orders.

## Features
- User registration and login
- Product listing and product details
- Shopping cart and checkout
- Order management
- JWT authentication

## Tech Stack
- **Frontend:** React.js, TypeScript, Redux Toolkit, Bootstrap
- **Backend:** Python, Django, Django REST Framework
- **Database:** PostgreSQL
- **Authentication:** JWT

## Project Structure
- `client/` – React frontend
- `server/` – Django REST API backend

## Getting Started
Clone the repository:

```bash
git clone https://github.com/Sahla-Thasni/style-co-ecommerce.git
```

Follow the frontend and backend setup instructions in their respective folders.
